El caso: la jornada de integración deportiva (10º y 11º)

Cuatro equipos, ocho jugadores y seis partidos: así quedó el torneo de la jornada de integración deportiva entre los grados 10.º y 11.º. Estas son las tres tablas de la base de datos del torneo: equipo (los equipos que jugaron), jugador (quiénes jugaron y cuántos goles hizo cada uno) y partido (cada partido con su marcador). Cómo crear las tablas (por si quiere probar en su propio SQLite)

CREATE TABLE equipo (
  id_equipo INTEGER PRIMARY KEY AUTOINCREMENT,
  nombre    TEXT NOT NULL,
  grado     TEXT NOT NULL
);

CREATE TABLE jugador (
  id_jugador INTEGER PRIMARY KEY AUTOINCREMENT,
  nombre    TEXT NOT NULL,
  id_equipo INTEGER NOT NULL,
  goles     INTEGER NOT NULL,
  FOREIGN KEY (id_equipo) REFERENCES equipo(id_equipo)
);

CREATE TABLE partido (
  id_partido      INTEGER PRIMARY KEY AUTOINCREMENT,
  fecha           TEXT NOT NULL,
  id_local        INTEGER NOT NULL,
  id_visitante    INTEGER NOT NULL,
  goles_local     INTEGER NOT NULL,
  goles_visitante INTEGER NOT NULL,
  FOREIGN KEY (id_local) REFERENCES equipo(id_equipo),
  FOREIGN KEY (id_visitante) REFERENCES equipo(id_equipo)
);
